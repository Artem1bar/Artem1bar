## Building now

- [**plumb**](https://github.com/Artem1bar/plumb), an AI co-pilot for HVAC technicians on ServiceTitan: answers from a knowledge base Claude builds from the shop's manuals and past jobs, and drafts the invoice from the on-site conversation. Technical co-founder; 2,500+ tests, in active development. Private repository.
- [**DataPilot**](https://github.com/Artem1bar/datapilot): upload a spreadsheet, describe the analysis in plain English; Claude picks the method and runs real statistics (33 scipy / pandas / statsmodels operations), every number measured, never generated. Outlier detection, cleaning catalog, scatter/bubble plotter, and plan review included. 1,979 tests. Runs locally with docker compose; the hosted frontend is waiting on a backend host.
- [**polymarket-trader**](https://github.com/Artem1bar/polymarket-trader): automated trading bot for Polymarket prediction markets. Endcycle sniper for 5-minute BTC/ETH Up/Down markets (buys high-probability tokens in the final 30–60 seconds), with Kelly sizing, stale-data gates, and a 500 ms late-exit safety net. Tennis underdog flip strategy in Phase 4 shadow mode: buy 5¢ underdog pre-match, exit on first re-price. 1,200+ tests across three modules.
- [**g1bridge**](https://github.com/Artem1bar/g1bridge): a Claude agent on Even Realities G1 smart glasses over Bluetooth LE. Reads the glasses' inputs, pushes a custom heads-up display, transcribes voice captured on the glasses.
- [**AI Literacy App**](https://github.com/Artem1bar/ai-literacy-app): role-adaptive modules on how LLMs work, prompting, and responsible AI, for students, professors, and developers. Reworked into the [AI 101 guides](https://weblux.co/ai-101) for business owners. [Live](https://ai-literacy-app-seven.vercel.app)
- **Business Command Hub**: local-first operations dashboard with per-division Claude agents, three gated overnight coding loops, six maintenance timers, and the server, all macOS LaunchAgents. 180+ API endpoints, 1,800+ tests. Its LSU page is my study system: it syncs my Moodle calendar every morning, tracks each course's grade against a target, has a Claude agent that writes a daily plan, and turns syllabi and textbooks into concept maps, concept cards, timed mocks, and drills. Private.

## Open-prompt experiments

Four projects from one series: an empty folder, Claude Code, and a single instruction to build whatever it found interesting and make it good. I set the constraints and shipped what held up.

- [**morphogen**](https://github.com/Artem1bar/morphogen): twelve generative and artificial-life systems in one dependency-free page. [Live](https://morphogen-rho.vercel.app)
- [**halting-problem**](https://github.com/Artem1bar/halting-problem): seeded generative art that halts Lorenz, Gray-Scott, and basin fields into STL, SVG, and DXF for print, CNC, and laser.
- [**gearworks**](https://github.com/Artem1bar/gearworks): an involute gear-train playground in a single HTML file. [Live](https://gearworks-silk.vercel.app)
- [**mythos-building**](https://github.com/Artem1bar/mythos-building): a dependency-free procedural mythology generator with its own phonology, pantheon, and star map. [Live](https://mythos-building.vercel.app)

## Hardware and math

- [**wndr-os**](https://github.com/Artem1bar/wndr-os): ESP32-S3 firmware for a pocket Tamagotchi-style device that asks people wonder questions, tells facts, and runs party games. 60 fps render loop, gesture input, sleep and wake.
- [**roboarm**](https://github.com/Artem1bar/roboarm): simulator-complete control software for a planned carbon-Kevlar 6-DOF arm. Inverse kinematics, trajectories, PID, safety monitor, web hub. No physical arm yet.
- [**fuelfleet**](https://github.com/Artem1bar/fuelfleet): a fleet-level fusion fuel-supply and deployment-economics model. Tritium, Li-6, learning rates, Monte Carlo.
- **ionic-wind-contactless-manipulation**: research project started as an ENGL 2000 paper and grown into a viability study — can corona-driven ionic wind lift and steer small objects without contact? Includes first-principles derivations, checks against published thrusters, an interactive explorer, a 3D time-domain IonLab simulator, and a bench module design for measuring the three unknowns. Private.

- [**command-hub**](https://github.com/Artem1bar/command-hub): local-first operations dashboard (Next.js 15, SQLite) for multiple business divisions. Manufacturing module is fully functional — machine status board, job queue, materials inventory, quoting calculator. Switchboard HUD (`/switchboard`) for social, messages and analytics. Other divisions are stubs.
- [**on-my-plate**](https://github.com/Artem1bar/on-my-plate): Claude artifact dashboard for GitHub — review requests, open PRs with CI badges, assigned issues, and mention notifications, all pulled live via the GitHub MCP connector.
- [**cengage-tutor**](https://github.com/Artem1bar/cengage-tutor): Playwright automation agent for Cengage MindTap. Syncs due dates, surfaces upcoming work, and auto-handles ungraded engagement busywork — page-view checkboxes, video-watched pings, Continue buttons, Aplia P&A clicks. Never touches graded work.
- [**documake**](https://github.com/Artem1bar/documake): local-first PDF generator for invoices, quotes, SOWs, and NDAs. Data never leaves the browser.
